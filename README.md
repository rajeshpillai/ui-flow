# 🔧 React Schema-Driven UI Builder

This project is a **low-code form and grid rendering engine** using React + Vite + TypeScript. It dynamically builds complex forms, tables, and layouts based on a JSON schema definition — supporting inline and external schema files.

## 📦 Features

- ✅ Master/Detail forms (inventory, candidates, etc.)
- ✅ Grid/Table rendering with:
  - Dropdowns, lookups, remote validation
  - Row-level actions (Save/Delete)
  - Calculated fields
  - Pagination (backend)
- ✅ Menu generated from schema
- ✅ Dynamic page routing (`/inventory`, `/candidates`, etc.)
- ✅ Split-schema support (inline or external JSON)
- ✅ Schema extensibility (tabs, sections, popups, modals, etc.)
- ✅ Mock Express.js APIs for testing
